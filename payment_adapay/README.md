## 🛠️ Installation

### Method 1: From Source

1. Clone this repository:
   ```bash
   git clone <your-repository-url>
   ```

2. Copy the module to your Odoo addons directory:
   ```bash
   cp -r payment_adapay /path/to/odoo/addons/
   ```

3. Update the app list in Odoo:
   - Go to **Apps** menu
   - Click **Update Apps List**

4. Search for **"ADA Payment"** and click **Install**

## ⚙️ Configuration

### Step 1: Enable Developer Mode

1. Go to **Settings** → Activate **Developer Mode**

### Step 2: Configure Payment Provider

1. Navigate to **Accounting** → **Configuration** → **Payment Providers**
2. Find **AdaPay** in the list and click **Configure**
3. Enter your AdaPay credentials:
   - **API Key**: Your AdaPay API key
   - **Public API Key**: Your public API key
   - **Environment**: Select Test or Production
   - **API URLs**: Configure your checkout API endpoints

### Step 3: Activate Payment Method

1. Go to **Accounting** → **Configuration** → **Payment Methods**
2. Enable **AdaPay** payment method
3. Configure payment terms and conditions

## 💡 Usage

### For Customers

1. Customers can select **AdaPay** during checkout
2. They will be redirected to a secure payment page
3. Complete payment using Cardano (ADA) cryptocurrency
4. Receive instant confirmation and order updates

### For Business Owners

1. **Invoice Payments**: Click the **E-pay** button on any invoice to generate a payment link
2. **Transaction Monitoring**: Track all payments in **Accounting** → **Payments**
3. **Reports**: Access comprehensive payment reports and analytics
